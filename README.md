# 🏆 AI基金经理挑战赛

> **创建你的基金，与AI一较高下，发现你的投资人格**

Vibe Coding 大赛参赛作品 — 一场用户与AI同台竞技的投资模拟挑战赛。选择你的股票，设定权重，与7位AI对手同场回测，获得幽默有梗的投资风格诊断。

## 🚀 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 生成股票数据（首次运行）
node server/generate-stocks.js

# 3. 启动服务（生产模式，端口 21818）
node start.js

# 或开发模式（前端热更新 + API分离）
node start.js --dev
```

访问 **http://localhost:21818** 开始使用。

## 🎮 使用流程

1. **创建基金** — 输入基金名称，选择3-10只成分股，调整权重
2. **开始挑战** — 选择回测周期，点击按钮与AI对手同台竞技
3. **查看排行** — 8条收益曲线对比，关键指标一览
4. **风格诊断** — 获得投资人格标签，对标知名人物，AI幽默点评

## ⚙️ 配置

### DeepSeek API（可选）

设置环境变量以启用AI幽默点评：

```bash
export DEEPSEEK_API_KEY="your-api-key"
```

不配置时自动使用预置幽默点评模板，体验同样出色。

### 部署端口

默认端口 `21818`（比赛规范要求）。可通过环境变量修改：

```bash
PORT=8080 node start.js
```
