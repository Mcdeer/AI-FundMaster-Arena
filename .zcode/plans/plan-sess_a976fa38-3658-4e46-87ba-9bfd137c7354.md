# 🏆 AI基金经理挑战赛 — 修订方案 v2

## 一、产品定位

一场用户与AI同台竞技的投资模拟挑战赛。创建自己的基金 → 与大盘基准+AI策略对手对决 → 获得**幽默有梗**的风格诊断。

**Slogan**：「创建你的基金，与AI一较高下，发现你的投资人格」

---

## 二、技术创新点（比赛加分项）

| 亮点 | 描述 |
|------|------|
| 🌍 跨市场 | A股+港股+美股，全球化选股 |
| 🤖 多策略AI | 4种AI策略 + 3个大盘基准，共8条收益曲线对比 |
| 😂 幽默诊断 | 股民梗文化 + 对标知名基金经理/机构 |
| 🎨 视觉炫技 | Vite构建 + 暗色科技风 + ECharts动画 + CSS动效 |

---

## 三、技术架构（极简高效）

```
前端 (Vite + 原生JS)      后端 (Node.js/Express)      外部服务
┌──────────────────┐      ┌─────────────────────┐     ┌──────────┐
│ Vite 开发/构建    │      │ server.js (端口21818)│     │ DeepSeek │
│ TailwindCSS 样式 │◄────▶│ /api/backtest        │     │ API      │
│ GSAP 轻量动画    │      │ /api/style-analysis  │     │ (风格点评)│
│ ECharts 图表     │      │ backtest.js (引擎)   │     └──────────┘
│ 暗色玻璃态主题   │      │ opponents.js (策略)  │
└──────────────────┘      │ stocks.json (数据)   │
                          └─────────────────────┘
```

| 层级 | 技术选型 | 为什么炫技 |
|------|---------|-----------|
| 构建 | **Vite** | 毫秒级HMR，现代工程化标杆 |
| 样式 | **TailwindCSS** | 原子化CSS，开发体验丝滑 |
| 动画 | **GSAP**（可选）或纯CSS | 流畅的页面过渡和数字跳动 |
| 图表 | **ECharts** | 金融级交互图表 |
| 主题 | **暗色科技风 + Glassmorphism** | 毛玻璃卡片、霓虹渐变色、粒子背景 |
| 后端 | Node.js + Express | 单文件即可跑，零额外依赖 |

## 八、页面设计（3屏单页）

### 第1屏：🏗️ 创建基金
- 暗色背景 + 粒子动画
- 横向滑动选择股票卡片（A股/港股/美股 tab切换）
- 每个股票卡片：名称、代码、行业标签、PE、近1年涨跌幅
- 已选股票拖拽排序，权重滑块实时调整
- 环形图展示行业分布
- 回测周期选择按钮组
- [⚡ 开始挑战] 发光按钮

### 第2屏：⚔️ 竞技场
- 顶部：排行榜（带金色/银色/铜色高亮）
- 中间：8条收益曲线的ECharts图（彩色+虚线区分基准）
- 可点击任意对手查看持仓明细
- 下方：关键指标对比表格（收益/回撤/夏普/波动率）
- 数字跳动动画

### 第3屏：🧠 风格诊断
- 大字风格标签 + 对标人物头像（渐变卡片）
- ECharts雷达图：5维度（收益/风险/换手/集中度/跨市场）
- AI幽默点评气泡
- [🔄 再来一局] 按钮 + [📤 分享截图]

## 十一、风险应对

| 风险 | 对策 |
|------|------|
| DeepSeek API 不可用 | 降级为预置点评模板库（随机抽取+填空），体验不差 |
| 跨市场数据量过大 | 按需懒加载，初始只加载所需周期数据 |
| 2C4G资源不够 | 全是静态计算+缓存，无数据库，内存占用<500MB |
| Vite构建复杂 | 发布时构建一次，运行时纯静态文件
